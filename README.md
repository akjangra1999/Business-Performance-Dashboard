# 📊 Business Performance Dashboard (Excel)

## 📌 Project Overview

This project is an interactive **Business Performance Dashboard** built entirely in **Microsoft Excel**.

The purpose of this dashboard is to analyze and monitor business performance across revenue, profit, store performance, and customer insights.

It helps stakeholders quickly understand key metrics and make data-driven decisions using a clean and interactive visual layout.

---

## 🎯 Objectives

- Monitor Total Revenue vs Target
- Track monthly performance trends
- Analyze store-wise sales performance
- Identify variance (positive & negative)
- Understand profit margin distribution
- Analyze category and customer insights

---

## 🛠 Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Slicers (Month & Category Filters)
- KPI Cards
- Data Cleaning
- Dashboard Design

## 📊 Key Insights

### ✅ Overall Performance
- **Total Revenue:** $5.4M  
- **Total Target:** $5.3M  
- **Variance:** +3.7%  
- **Profit Margin:** 42.2%  

The business is performing slightly above target with a healthy profit margin.

---

### 🏬 Store-Level Insights
- Some stores are significantly exceeding targets.
- A few stores show negative variance, indicating areas for improvement.
- Store comparison helps identify high-performing vs underperforming locations.

---

### 📅 Monthly Trend Analysis
- Revenue fluctuations observed across months.
- Certain months show strong growth spikes.
- Seasonal patterns can be identified using monthly filters.

---

### 👥 Customer & Category Insights
- Profit contribution varies by age group.
- Category-level analysis shows top-performing product segments.
- Gender-based profit distribution is clearly visualized.

---

## 🚀 How to Use the Dashboard

1. Use the **Month Filter** to analyze performance by specific months.
2. Use the **Store Filter** to compare store-level performance.
3. Review KPI cards at the top for quick performance insights.
4. Analyze charts to identify trends and variance patterns.
